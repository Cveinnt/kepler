# Recorded sp80 replay assets

21 unchanged PNG observations from the public August 28, 2026 development run, event 8324. Source: https://www.wensenwu.com/thoughts/kepler (public/blog/kepler/sp80-win/frame-00.png through frame-20.png in the personal-site repository). These are not frames from the later release scorecard.

replay.js only switches recorded images; it runs no model or simulator. Settled mode shows frames 0 and 20 only, as a viewing aid, not an experiment.

MP4/GIF exports: 4 source frames per second, final frame held two seconds. MP4 is 512x512 H.264, 7.25 seconds, no audio. Original PNGs remain the evidence.
